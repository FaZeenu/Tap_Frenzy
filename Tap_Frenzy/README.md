# PlayHub

PlayHub is an iOS application that combines three games developed during the iOS Application Development tutorials: Tap Frenzy, Light It Up, and Quiz Rush.

## Architecture Overview

The application is organised into different sections to keep the project simple and easy to manage.

- **App** – Contains the main application setup.
- **Games** – Contains the three game screens:
  - Tap Frenzy
  - Light It Up
  - Quiz Rush
- **Models** – Contains the data models used by the application.
- **Views** – Contains the user interface screens.
- **Shared Components** – Contains reusable UI components used across the app.

The application uses a tab-based structure with four main sections:

- Home
- Stats
- Map
- Settings

## Features

### Home
- Provides access to the three games.
- Tap Frenzy
- Light It Up
- Quiz Rush

### Tap Frenzy
- Tap-based gameplay.
- Calculates and displays the player's score.
- Shows the game result.

### Light It Up
- Light-based gameplay.
- Calculates and displays the player's score.
- Shows the game result.

### Quiz Rush
- Quiz-based gameplay.
- Displays questions and answers.
- Calculates and displays the final score.

### Stats
- Displays game statistics.
- Shows completed game results.
- Displays recent game information.

### Map
- Map screen is included in the application structure.
- Location-based functionality is not implemented in the current version.

### Settings
- Settings screen is included in the application structure.
- Settings functionality is not implemented in the current version.

## Known Limitations

- Map functionality has not been fully implemented.
- Core Location and game location tracking are not currently implemented.
- Settings functionality is not fully implemented.
- Notifications and Daily Challenge functionality are not implemented.
- Some advanced features planned for the application are not available in the current version.

## Reflection

This project helped me improve my understanding of iOS application development using Xcode and Swift.

I learned how to combine multiple games into one application and organise the application using different screens and navigation.

I also improved my understanding of user interface design, game logic, score handling, and structuring an iOS project.

The project also helped me identify areas that can be improved in the future, such as implementing the Map, location tracking, notifications, and Settings functionality.
